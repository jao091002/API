# Painel de estoque

Aplicação com front-end em Next.js/React e API Express com MySQL.

## Preparação

1. Instale o Node.js 20.9 ou superior.
2. Execute `npm install`.
3. Configure `.env` com `DB_HOST`, `DB_USER`, `DB_PASSWORD`, `DB_NAME` e `DB_PORT`.

## Executar

Na pasta do projeto, execute:

- `npm run dev` (inicia o site e a API em `http://localhost:3000`)
- `npm run build` e `npm start` para gerar e executar a versão de produção.

Para trocar a porta do site e da API, configure `APP_PORT`.
